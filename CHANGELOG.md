## [0.1.0]

### Added

- Initial `gsc` CLI with Search Console commands for auth, sites, analytics, URL inspection, and sitemaps.
- Multi-account local credential storage and installed-app OAuth flows (loopback and manual modes).
- Structured output modes (`table`, `--plain`, `--json`) for interactive use and scripting.
- Prebuilt binaries for macOS, Linux, and Windows, plus Homebrew installation support.
